# SpeedFast - Semana 6

Proyecto Java Swing para la gestión de pedidos de SpeedFast.

## Estructura
- `modelo`: clases del modelo y lógica del proyecto anterior.
- `vista`: ventanas gráficas Swing.
- `main`: punto de entrada de la aplicación.

## Ejecución
Abrir el proyecto en IntelliJ IDEA y ejecutar:
`src/main/Main.java`

## Funciones
- Registrar pedidos.
- Seleccionar tipo: comida, encomienda o express.
- Validar datos.
- Listar pedidos en JTable.
- Actualizar tabla.
- Asignar repartidor automáticamente.
- Iniciar despacho.
